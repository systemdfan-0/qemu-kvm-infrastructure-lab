# Проверки и результаты перезагрузки

[Главная](../../README.ru.md) · [English](../en/validation.md) | **Русский**

Это сводка итоговой разрешённой проверки от 7 ноября 2026 года. При подготовке репозитория новый live-аудит не проводился. Закрытые итоговые отчёты аудита, тестов, безопасности, перезагрузки и восстановления имеют приоритет над старой инвентаризацией. Сырые доказательства остаются закрытыми: репозиторий содержит очищенный отчёт, а не архив для независимого воспроизведения доказательств.

PASS означает совпадение наблюдаемого результата с ожиданием в указанном объёме; ожидаемый запрет считается PASS. NOT TESTED означает отсутствующую или неиспытанную функциональность. Использованы ограниченные HTTP HEAD/GET, SSH banner/TCP и ICMP-пробы внутри лаборатории. Успешное чтение SSH banner не подтверждает аутентификацию.

Каждый гость прошёл одну разрешённую перезагрузку. Подтверждением служили смена boot ID и возврат QGA; сами идентификаторы исключены. С baseline сравнивались IPv4-адреса/префиксы/интерфейсы, destination/gateway/device маршрутов, forwarding и необходимые units. Ручное аварийное восстановление не потребовалось. Forwarding включён у двух маршрутизаторов и выключен у остальных четырёх гостей. Итоговая сетевая матрица выполнена после возврата всех шести.

Необходимые units восстановились; failed units — ноль. Сохранённые и действующие firewall-правила совпали; `iptables-restore --test` завершился успешно. В наблюдаемом boot firewall завершился до ifup/networking; это подтверждение порядка запуска, а не непрерывный packet capture. Ошибки необязательного AF_VSOCK generator сохранились; см. [безопасность](security.md).

Hairpin NAT не настроен; LAN использует частный DMZ HTTP.

## Защита служб и проверка восстановления

Оба HTTP-узла прошли отдельные проверки restart и reboot: непривилегированный runtime user, только `CAP_NET_BIND_SERVICE`, `NoNewPrivileges`, read-only mount и root-owned каталог/файлы (0755/0644). Три искусственные escape-пробы на каждом узле вернули 404 без раскрытия несекретного root-canary; тестовые артефакты удалены. Реальные учётные данные не читались и не запрашивались.

Свежие конфигурационные архивы всех шести гостей прошли checksum, сравнение и отдельную распаковку. Хеши экспортированных копий совпали. Проверены валидация восстановления правил и синтаксис rollback-скрипта; безвредная timer-проба прошла повторно после явной настройки точности таймера. Первоначальная диагностическая ошибка времени не засчитывалась как сетевой PASS. Аварийный откат не потребовался и не выполнялся.

## NOT TESTED / ограничения

| Сценарий | Причина |
|---|---|
| Отдельный исходящий DMZ SNAT | Policy запрещает новые DMZ → WAN; счётчик правила остался нулевым |
| HTTPS/TLS и DNS resolution | Нет TLS listener и гостевого nameserver; IP-only |
| SSH-аутентификация | Только transport/configuration; пароли и ключи не менялись |
| Полный restore ВМ / аварийный rollback | Только проверки конфигурационных копий; полный образ не восстанавливался |
| Все протоколы / IPv6 / альтернативные host paths | Только выбранные IPv4-пути; правила хоста независимо не проверены |
| Внешняя сеть / Интернет | Вне области проверки; у ISP router нет default route |
| Reboot хоста / power-cycle / отказ загрузки firewall | Не выполнялись; проверен один guest reboot-цикл |
| Live-поведение вспомогательных ВМ | Три вспомогательных гостя оставались выключенными |

Конфигурационные копии находятся на том же физическом хосте и не являются независимым off-host backup. Гарантии RPO/RTO не установлены. Будущие обновления, hotplug и отказы хранилища не испытаны. См. [безопасность и остаточные риски](security.md).
